## About

I am an AI / ML Research Engineer based in Sousse, Tunisia. I build language and retrieval systems with an evaluation-first approach: retrieval strategy, model choice, and fine-tuning decisions should be supported by a clear measurement protocol rather than intuition.

My current interests include reliable RAG, hybrid SQL + vector retrieval, transformer training, parameter-efficient fine-tuning, model evaluation, and experiment tracking.
